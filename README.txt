КАК ПОЛУЧИТЬ .APK ДЛЯ ANDROID (без установки программ на компьютер)

1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Нажмите "+" -> New repository. Имя любое, например koleso. Создайте.
3. Распакуйте этот архив. На странице репозитория нажмите
   "uploading an existing file" и перетащите ВСЁ содержимое папки
   (включая скрытую папку .github — если не видно, включите показ скрытых файлов).
   Нажмите Commit changes.
4. Откройте вкладку Actions. Сборка стартует сама (5-10 минут).
   Если не стартовала: Actions -> Build Android APK -> Run workflow.
5. Когда появится зелёная галочка, откройте запуск и внизу в разделе
   Artifacts скачайте koleso-i-kosti-apk (zip). Внутри app-debug.apk.
6. Перенесите app-debug.apk на телефон и откройте его.
   Android попросит разрешить установку из неизвестных источников — разрешите.

Чтобы обновить сайт: замените www/index.html в репозитории и сделайте commit.
Нужен интернет в телефоне (шрифты Google и Firebase грузятся из сети).
